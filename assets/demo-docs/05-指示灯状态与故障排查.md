# 指示灯状态说明与常见故障排查

## 一、适用条件
本文件适用于星云智联 AX6000（NL-AX6000）的指示灯解读与常见故障自助排查。适用于设备通电后异常、无法上网、频繁掉线等场景。排查前请准备好机底 SN 与现象描述，便于必要时联系售后。

## 二、指示灯状态全表
| 指示灯 | 状态 | 含义 | 处置 |
|---|---|---|---|
| 电源 Power | 蓝常亮 | 通电正常 | 无需处理 |
| 电源 Power | 不亮 | 未通电/电源故障 | 查电源 |
| 系统 SYS | 蓝常亮 | 运行正常 | 无需处理 |
| 系统 SYS | 蓝闪烁 | 启动/处理中 | 稍候 |
| 系统 SYS | 红常亮 | 系统故障 | 联系售后 |
| WAN | 绿常亮 | 已联网 | 无需处理 |
| WAN | 绿闪烁 | 数据收发 | 正常 |
| WAN | 不亮 | 未连接 | 查光猫/网线 |
| WiFi | 蓝常亮 | 无线开启 | 无需处理 |
| WiFi | 不亮/红 | 关闭/异常 | 查设置 |

## 三、故障一：上电后电源灯不亮
1. 检查电源适配器是否插紧 DC 12V 口与插座。
2. 换插座或用其他电器验证插座有电。
3. 观察适配器指示灯（如有）是否亮。
4. 更换电源适配器测试（需同规格 DC 12V/1.5A）。
5. 仍不亮：可能适配器或主板故障，联系售后。

## 四、故障二：系统灯红色常亮
1. 记录红灯现象，不要反复断电。
2. 尝试后台重启（若可登录）。
3. 若无法登录且红灯持续：系统故障，联系售后并提供机底 SN。
4. 如刚升级完出现红灯，说明升级异常，按 04 文档联系售后。

## 五、故障三：WAN 口灯不亮、无法上网
1. 确认光猫已通电并可上网。
2. 检查光猫到 WAN（蓝色）口的网线两端插紧。
3. 更换网线排除线材问题。
4. 确认网线插的是蓝色 WAN 口而非黄色 LAN 口。
5. 检查后台上网方式是否为 PPPoE 且账号密码正确。
6. 仍不亮：联系运营商确认宽带状态。

## 六、故障四：能连 WiFi 但打不开网页
1. 确认 WAN 口灯绿色常亮（已联网）。
2. 检查上网方式是否为 PPPoE 且账号密码正确。
3. 尝试修改 DNS 为自动获取。
4. 用网线接 LAN 口直连测试是否手机问题。
5. 重启路由器后观察是否恢复。

## 七、故障五：网速慢或不稳定
1. 确认连接的是 5G 还是 2.4G，距离远建议靠近或切 2.4G。
2. 检查是否超过 128 台带机量。
3. 排查附近微波炉、蓝牙等干扰源。
4. 检查固件是否为最新（见 04 文档）。
5. 用网线接 LAN 口测速，判断是无线还是宽带问题。

## 八、故障六：频繁掉线
1. 统计当前联网设备数量，确认是否超过 128 台。
2. 观察掉线是否发生在特定设备，排查该设备兼容性。
3. 检查路由器散热与周围温度，避免超过 40°C。
4. 尝试将 2.4G 与 5G 分设不同名称，避免双频合一导致旧设备不稳定。
5. 若仍频繁掉线，先重启而非立即恢复出厂，重启可排除临时故障。

## 九、限制与环境因素
- 同时设备超过 128 台会限速或掉线。
- 附近强干扰（微波炉、蓝牙）影响 2.4G。
- 环境温度超出 0°C~40°C 或散热差会不稳定。
- WAN 口为 2.5G，但实际速率受宽带套餐限制。
- 墙体材质（如金属、承重墙）会显著衰减信号。

## 十、成功判断标准
- 电源灯蓝常亮、系统灯蓝常亮、WAN 灯绿常亮。
- 手机/电脑可正常浏览网页且速率符合预期。
- 异常现象按上述步骤消除。

## 十一、失败处理
- 按步骤仍无法解决：记录指示灯状态与现象。
- 系统红灯、电源不亮属硬件问题，直接联系售后。
- 忘记密码导致无法进后台：恢复出厂（见 04）。
- 频繁掉线优先排查带机量与干扰，而非立即恢复出厂。

## 十二、注意事项
> **安全提示：** 排查时请勿自行拆机，拆机将失去保修；异常发热或异味请立即断电并联系售后。

- 故障描述请包含型号 NL-AX6000 与指示灯状态，便于售后定位。
- 频繁掉线优先排查带机量与干扰，而非立即恢复出厂。

## 十三、常见问题
**Q1：系统灯红色常亮是什么故障？**
A1：星云智联 AX6000（NL-AX6000）系统灯红常亮表示系统故障。请勿反复断电，若无法登录后台，请记录现象并联系售后，提供机底 SN 以便处理。

**Q2：WAN 口灯不亮但已插网线？**
A2：针对星云智联 AX6000（NL-AX6000），WAN 灯不亮多为光猫未联网、网线松脱或插错口。请确认网线插在蓝色 WAN 口且光猫正常，必要时更换网线。

**Q3：能连 WiFi 却打不开网页？**
A3：星云智联 AX6000（NL-AX6000）能连 WiFi 但无网，通常是 WAN 未联网或宽带拨号账号错误。请确认 WAN 灯绿常亮、上网方式 PPPoE 账号密码正确。

**Q4：频繁掉线怎么排查？**
A4：星云智联 AX6000（NL-AX6000）频繁掉线，先查是否超过 128 台带机量、附近是否有微波炉干扰、散热是否良好；排除后仍掉线可尝试重启，勿直接恢复出厂。

**Q5：电源灯不亮但适配器发热？**
A5：星云智联 AX6000（NL-AX6000）电源灯不亮且适配器发热，可能电源或主板故障，请立即断电，不要继续通电，联系售后检测，避免安全隐患。

**Q6：WiFi 灯不亮是什么意思？**
A6：星云智联 AX6000（NL-AX6000）的 WiFi 灯不亮或变红表示无线功能关闭或异常。可登录后台检查无线开关是否开启；若开启仍不亮，尝试重启或恢复出厂。

**Q7：网速慢和带机量有关吗？**
A7：有关。星云智联 AX6000（NL-AX6000）建议带机量 ≤128 台，连接设备过多会分摊带宽并可能引起限速或掉线，可减少设备或使用 Mesh 扩展覆盖。

**Q8：升级后系统红灯怎么办？**
A8：星云智联 AX6000（NL-AX6000）若固件升级后出现系统灯红常亮，说明升级异常，请勿反复断电，记录现象并联系售后处理。

**Q9：所有灯都不亮是什么情况？**
A9：星云智联 AX6000（NL-AX6000）若电源灯、系统灯全不亮，多为未通电或电源适配器故障。请检查插座与适配器连接，更换同规格电源测试，仍不行联系售后。

**Q10：WiFi 灯亮但搜不到信号？**
A10：星云智联 AX6000（NL-AX6000）若 WiFi 灯蓝常亮却搜不到信号，可能是隐藏了 SSID 或频段选择问题。请登录后台确认无线已开启且未隐藏名称，或尝试重启。

**Q11：系统灯一直蓝闪不转常亮？**
A11：星云智联 AX6000（NL-AX6000）系统灯蓝闪表示启动或处理中。若长时间（超过数分钟）仍为蓝闪且无法上网，可能是配置写入异常，可重启或恢复出厂后重设。

**Q12：WAN 灯绿闪但不稳定上网？**
A12：星云智联 AX6000（NL-AX6000）WAN 灯绿闪说明正在收发数据，若上网不稳定，多为线路质量、带机量或干扰问题，可按故障五、六逐步排查。

## 附录：故障补充问答

**Q13：网速突然变慢先查什么？**
A13：星云智联 AX6000（NL-AX6000）网速骤降时，先确认是否有人在大流量下载、是否超过 128 台带机量，再用网线直连测速判断是宽带还是无线问题。

**Q14：某个房间信号特别差？**
A14：星云智联 AX6000（NL-AX6000）单台覆盖有限，若某房间差，可调整路由器位置，或用同型号子节点组 Mesh 补盲，而非盲目提高发射功率。

**Q15：重启后指示灯正常但仍不能上网？**
A15：星云智联 AX6000（NL-AX6000）若灯全正常却无网，多为宽带侧问题，检查 WAN 灯是否绿亮、宽带账号是否有效，或联系运营商确认。

**Q16：WiFi 频繁断但有线正常？**
A16：星云智联 AX6000（NL-AX6000）若仅无线不稳、有线正常，多为无线干扰或双频合一兼容问题，可关闭双频合一、分设频段或改信道尝试。

**Q17：夜间掉线白天正常？**
A17：可能与干扰或定时任务有关。星云智联 AX6000（NL-AX6000）若夜间异常，排查附近同频设备，并检查是否设置了定时重启等计划任务。

**Q18：指示灯全亮但管理页面进不去？**
A18：星云智联 AX6000（NL-AX6000）若灯正常但打不开 192.168.10.1，先确认设备连的是本机网络，或更换浏览器、清缓存后重试，必要时重启。

**Q19：换了光猫上不了网？**
A19：星云智联 AX6000（NL-AX6000）更换光猫后，需确认新光猫上网方式，并重新在天蓝色 WAN 口接线；若新光猫已拨号，本机改“自动获取 IP”即可。

**Q20：设备连上 WiFi 但显示无互联网？**
A20：星云智联 AX6000（NL-AX6000）此类现象多为 WAN 未联网或 DNS 异常，确认 WAN 灯绿亮、上网方式正确，并尝试将 DNS 设为自动获取。

## 延伸问答

**Q21：全屋都卡是路由器问题？**
A21：不一定。星云智联 AX6000（NL-AX6000）全屋卡先查宽带与带机量，再用网线测速区分是宽带还是无线。

**Q22：某设备总掉线？**
A22：查该设备。星云智联 AX6000（NL-AX6000）单设备掉线多为终端兼容或省电设置，可忘记网络重连。

**Q23：雷雨后不能用？**
A23：可能雷击损坏。星云智联 AX6000（NL-AX6000）雷雨建议断电，若雷后故障多为硬件，联系售后。

**Q24：系统灯蓝闪很久？**
A24：启动中。星云智联 AX6000（NL-AX6000）蓝闪为正常启动，超过数分钟异常可重启或恢复出厂。

**Q25：WAN 灯绿但不走流量？**
A25：DNS 或账号。星云智联 AX6000（NL-AX6000）WAN 绿亮却无网，查 DNS 自动获取与宽带账号有效性。

**Q26：2.4G 连上没网 5G 正常？**
A26：可能 2.4G 干扰。星云智联 AX6000（NL-AX6000）2.4G 易受微波炉等干扰，可改信道或暂用 5G。

**Q27：重启能解决大多数问题？**
A27：多数临时故障能。星云智联 AX6000（NL-AX6000）重启保留配置，是首选排查动作，无效再深入。

**Q28：频繁重启伤设备？**
A28：偶尔不伤。星云智联 AX6000（NL-AX6000）正常重启无碍，但频繁异常重启可能预示硬件问题。

**Q29：指示灯都不亮但风扇转？**
A29：本机无风扇。星云智联 AX6000（NL-AX6000）无散热风扇，若全灯不亮多为未通电或电源故障。

**Q30：送修前怎么留证据？**
A30：拍照记录。星云智联 AX6000（NL-AX6000）送修前拍机底 SN、指示灯状态与故障现象，便于售后判定。

## 内容小结
本文讲解星云智联 AX6000（NL-AX6000）的指示灯与故障排查。电源蓝亮、系统蓝亮、WAN 绿亮为健康状态；系统红灯、电源不亮属硬件问题需售后。无法上网先查 WAN 灯与宽带账号，能连 WiFi 无网多为拨号或 DNS 问题。网速慢先确认带机量是否超 128 台与附近干扰，再用网线测速区分宽带与无线。频繁掉线优先重启而非恢复出厂，重启保留配置且能排除多数临时故障。全屋卡先查宽带，单设备掉线查终端兼容。雷雨后故障可能为硬件损坏。送修前拍照记录 SN 与指示灯状态。排查请勿自行拆机，异常发热立即断电，避免安全隐患与失去保修。
