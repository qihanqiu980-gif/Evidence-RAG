# WiFi 名称密码、访客网络与儿童上网管理

## 一、适用条件
本文件适用于星云智联 AX6000（NL-AX6000）的无线网络配置，包括修改 WiFi 名称与密码、访客网络、儿童上网管理。前提：已按 02 文档完成首次登录，且设备系统灯蓝常亮、WAN 口灯绿常亮。

## 二、准备工作
1. 手机或电脑连接本机 WiFi 或接 LAN 口。
2. 浏览器访问 http://192.168.10.1 并用管理员账号登录。
3. 确认固件为最新（见 04 文档），旧版本界面可能略有差异。
4. 准备好要设置的 WiFi 名称与密码。

## 三、默认无线参数
| 项目 | 默认值 |
|---|---|
| 2.4G WiFi 名称 | Nebula_AX6000 |
| 5G WiFi 名称 | Nebula_AX6000_5G |
| WiFi 密码 | 见机底标签（示例 nebula2025） |
| 双频合一 | 默认关闭，可手动开启 |

## 四、修改 WiFi 名称与密码步骤
1. 登录后台，进入“无线设置”。
2. 分别选择 2.4G 与 5G 频段。
3. 修改“无线网络名称（SSID）”与“无线密码”。
4. 建议密码含大小写字母、数字，长度 8 位以上，避免使用生日或连续数字。
5. 点击“保存”，路由器短暂重启后生效。
6. 用新密码重新连接 WiFi，确认可正常上网。

## 五、双频合一说明
开启双频合一后，2.4G 与 5G 使用同一名称，设备自动选择频段。优点是无须手动切换，体验更省心；缺点是部分旧设备可能连接不稳定。如不需要可保持分设，由用户自行选择更合适的频段。分设时，5G 名称带“_5G”后缀便于区分。若家中多为新款手机电脑，开启双频合一通常体验更好。

## 六、访客网络设置步骤
1. 后台进入“访客网络”。
2. 开启访客网络开关。
3. 设置访客 WiFi 名称与密码、有效时长（如 4 小时、8 小时或永久）。
4. 开启“隔离主网络”，使访客无法访问内网设备。
5. 保存后，访客连接对应名称即可限时上网。
6. 到期或手动关闭后，访客网络自动失效。

## 七、儿童上网管理步骤
1. 后台进入“家长控制”（儿童上网管理）。
2. 点击“添加设备”，从已连设备列表中选择孩子设备并绑定。
3. 设置允许上网时段（如 19:00 至 21:00）。
4. 选择网站分类限制（如游戏、视频、社交）。
5. 保存后，该设备在禁网时段将无法上网，允许时段正常。
6. 如孩子设备更换网卡，需重新绑定新识别信息。

## 八、功能限制
- 儿童上网管理仅按内置网站分类限制，不支持自定义单个 App 黑名单。
- 访客网络隔离后，访客不能访问打印机、NAS 等内网设备。
- USB 存储共享与 WiFi 设置互不影响。
- 双频合一开启时，2.4G 与 5G 名称合并，无法单独区分。
- 同一设备只能绑定到一个儿童管理策略。
- 儿童管理依赖设备识别，设备使用随机 MAC 时可能失效。

## 九、信号优化建议
- 2.4G 适合远距离与穿墙，5G 适合近距离高速。
- 若某房间信号弱，可调整天线角度或将路由器稍作移动。
- 大户型建议用 Mesh 扩展（见 04 文档）而非单纯提高功率。
- 避免将路由器与微波炉、蓝牙音箱放在同一位置。

## 十、成功判断标准
- 修改后的 WiFi 名称可被搜索到且用新密码连上。
- 访客网络按时长可用，且无法访问主网络设备。
- 儿童设备在禁网时段无法上网、允许时段正常。
- 后台对应开关状态与实际表现一致。

## 十一、失败处理
- 改密码后连不上：确认输入正确，注意大小写；若彻底遗忘只能恢复出厂重设（见 04）。
- 访客无法上网：检查是否过期、隔离是否误开限制、密码是否输错。
- 儿童管理不生效：确认设备已正确绑定，且设备未更换网卡或 MAC。
- 双频合一后旧设备掉线：关闭双频合一，分设两个频段名称。

## 十二、注意事项
> **安全提示：** WiFi 密码请勿使用生日、12345678 等弱密码，避免被蹭网；修改密码后请告知家庭成员，避免自己无法连接。

- 双频合一可能导致个别旧设备掉线，必要时关闭。
- 儿童管理依赖设备识别，设备更换网卡后需重新绑定。
- 访客网络请设置独立密码，避免主网络密码外泄。
- 建议为 2.4G 与 5G 设置不同密码以便排查。

## 十三、常见问题
**Q1：2.4G 和 5G 该连哪个？**
A1：星云智联 AX6000（NL-AX6000）的 2.4G 穿墙好、覆盖远，适合智能家居等低速设备；5G 速率高、干扰少，适合手机电脑高速上网。距离路由器远时建议用 2.4G。

**Q2：怎么改 WiFi 密码？**
A2：登录星云智联 AX6000（NL-AX6000）后台 http://192.168.10.1，进入“无线设置”，分别修改 2.4G 与 5G 的 SSID 与密码后保存即可，建议 8 位以上含字母数字。

**Q3：访客网络能访问我家电脑吗？**
A3：不能。星云智联 AX6000（NL-AX6000）的访客网络开启“隔离主网络”后，访客只能上网，无法访问您的主网设备（如电脑、打印机），保障内网安全。

**Q4：儿童上网管理能禁止某个 App 吗？**
A4：不能精确到单个 App。星云智联 AX6000（NL-AX6000）的儿童上网管理按内置网站分类（如游戏、视频）限制，并支持按设备与时段管控，暂不支持自定义 App 黑名单。

**Q5：双频合一要不要开？**
A5：星云智联 AX6000（NL-AX6000）默认关闭双频合一。若希望设备自动选频段、不想手动切换可开启；若旧设备频繁掉线，建议关闭并手动选择 2.4G/5G。

**Q6：改了密码家人连不上怎么办？**
A6：星云智联 AX6000（NL-AX6000）修改 WiFi 密码后，所有已存旧密码的设备需重新输入新密码。请告知家人新密码；若自己遗忘只能恢复出厂重设。

**Q7：访客网络能设多久？**
A7：星云智联 AX6000（NL-AX6000）的访客网络支持设置有效时长（如 4 小时、8 小时）或永久，到期后自动失效，也可随时在后台手动关闭。

**Q8：儿童管理能限制哪些内容？**
A8：星云智联 AX6000（NL-AX6000）的儿童上网管理可限制游戏、视频、社交等内置网站分类，并按设备与时段管控，但不能精确到单个 App，且依赖设备正确绑定。

**Q9：默认 WiFi 密码在哪里看？**
A9：星云智联 AX6000（NL-AX6000）的默认 WiFi 密码印制在机底标签上（示例为 nebula2025），首次设置时可修改为自定义密码。

**Q10：能不能把 2.4G 和 5G 设成同名？**
A10：可以。星云智联 AX6000（NL-AX6000）提供“双频合一”功能，开启后 2.4G 与 5G 使用同一名称，由设备自动选频段；若关闭则两者分设不同名称。

**Q11：儿童管理对笔记本电脑有效吗？**
A11：有效但有限。星云智联 AX6000（NL-AX6000）的儿童上网管理按绑定设备识别，笔记本电脑若更换网卡或使用随机 MAC，需重新绑定才能持续生效。

**Q12：访客网络需要单独设密码吗？**
A12：建议设置。星云智联 AX6000（NL-AX6000）的访客网络可设独立密码，避免主网络密码外泄；若留空，任何附近的人都可能连入，存在安全风险。

## 附录：无线设置补充问答

**Q13：WiFi 名称能用中文吗？**
A13：可以。星云智联 AX6000（NL-AX6000）的 SSID 支持中文名称，但部分旧设备可能对中文名兼容性稍差，如连接异常可改用字母数字名称。

**Q14：5G 信号满格但速度慢？**
A14：星云智联 AX6000（NL-AX6000）的 5G 速率受终端网卡与距离影响。若满格仍慢，先确认终端支持 WiFi 6，再用网线测速判断是否为宽带瓶颈。

**Q15：能不能隐藏 WiFi 名称？**
A15：可以。星云智联 AX6000（NL-AX6000）在无线设置中可隐藏 SSID，隐藏后设备需手动输入名称连接，安全性略高但不便访客使用。

**Q16：信道需要手动调吗？**
A16：一般不用。星云智联 AX6000（NL-AX6000）默认自动选择信道，在干扰多的环境若不稳定，可在后台手动指定较空闲信道尝试改善。

**Q17：儿童管理能按周末单独设吗？**
A17：星云智联 AX6000（NL-AX6000）的儿童上网管理以时段规则为主，可按每天设置允许时段；若需周末差异，可手动调整对应日期的时段后保存。

**Q18：访客网络能限速吗？**
A18：视固件版本而定。星云智联 AX6000（NL-AX6000）的访客网络重点是隔离与限时，是否支持精细限速以管理后台实际选项为准，本文不承诺未确认功能。

**Q19：改完设置家人手机要重连吗？**
A19：要。星云智联 AX6000（NL-AX6000）修改 WiFi 名称或密码后，所有已连设备都会断开，需用新名称或新密码重新连接，请提前告知家人。

**Q20：无线开关在哪里关？**
A20：星云智联 AX6000（NL-AX6000）在“无线设置”中可分别开关 2.4G 与 5G；关闭后对应 WiFi 灯会不亮或变红，需要时再开启即可。

## 延伸问答

**Q21：双频合一和频段优选一样吗？**
A21：不同。星云智联 AX6000（NL-AX6000）双频合一是同一名称自动选频段；若后台另有频段优选策略，以界面实际选项为准。

**Q22：客人来了怎么给网络？**
A22：开访客网络。星云智联 AX6000（NL-AX6000）在访客网络中设独立名称密码并限时，避免泄露主密码。

**Q23：儿童设备换了手机？**
A23：需重新绑定。星云智联 AX6000（NL-AX6000）儿童管理按设备识别，新设备要在家长控制中重新添加。

**Q24：5G 名字带_5G 能改吗？**
A24：能。星云智联 AX6000（NL-AX6000）在无线设置分别改 2.4G 与 5G 的 SSID，可去掉或保留_5G 后缀。

**Q25：WiFi 密码忘了？**
A25：登录后台改。星云智联 AX6000（NL-AX6000）管理员可进无线设置重置密码；若连不上且忘密码，只能恢复出厂。

**Q26：访客能看我家监控吗？**
A26：不能（隔离后）。星云智联 AX6000（NL-AX6000）访客网络开启隔离后，访客无法访问主网监控等内网设备。

**Q27：信号满格但视频卡？**
A27：多为干扰或带宽。星云智联 AX6000（NL-AX6000）可尝试切 5G、关双频合一或错峰，并确认非运营商问题。

**Q28：能限制孩子夜间游戏吗？**
A28：能。星云智联 AX6000（NL-AX6000）儿童管理设禁网时段（如 22:00-07:00），该设备在时段内无法上网。

**Q29：改 WiFi 名要重启很久？**
A29：很短。星云智联 AX6000（NL-AX6000）保存无线设置后数秒至一分钟重启生效，属正常。

**Q30：无线开关关了还能管理吗？**
A30：能。星云智联 AX6000（NL-AX6000）关无线后仍可用网线接 LAN 口或连已开频段进后台管理。

## 内容小结
本文介绍星云智联 AX6000（NL-AX6000）的无线设置。默认提供 2.4G 与 5G 两个频段，分别名为 Nebula_AX6000 与 Nebula_AX6000_5G，密码见机底标签。修改名称与密码在“无线设置”中完成，建议设置 8 位以上强密码。双频合一可让设备自动选频段，但旧设备可能不稳，必要时关闭分设。访客网络适合临时共享，开启隔离后无法访问内网，且可设有效时长自动失效。儿童上网管理可按设备与时段限制游戏、视频等分类，但不支持单个 App 黑名单。遇到改密后连不上、双频合一掉线或儿童管理不生效，可按文中失败处理逐项排查。无线开关可分别关闭 2.4G 与 5G，关闭后对应指示灯不亮或变红。合理设置能兼顾安全、覆盖与家庭管控需求。

> **温馨提示：** 无线设置是日常最常改动的部分。星云智联 AX6000（NL-AX6000）建议家庭主网络用强密码，访客用独立限时网络，儿童设备用时段管控，三者配合既能方便家人也能保障安全。修改名称或密码后，所有已连设备需用新信息重连。改动后若异常，优先重启或核对步骤，而非直接恢复出厂，避免不必要的重新配置与宽带账号再次录入。如长时间外出，可关闭无线或断电以省电并延长设备寿命。
