# Mesh 组网、固件升级与恢复出厂设置

## 一、适用条件
本文件适用于星云智联 AX6000（NL-AX6000）的 Mesh 多节点扩展、固件升级与恢复出厂设置。前提：主节点已按 02 文档完成联网，系统灯蓝常亮、WAN 口灯绿常亮。

## 二、准备工作
1. 主节点正常联网，系统灯蓝常亮。
2. Mesh 子节点同品牌、同型号 NL-AX6000、固件版本一致。
3. 准备一根网线（本地升级用）或 U 盘（本地固件）。
4. 准备针状物（如回形针）用于长按 Reset 键。

## 三、Mesh 组网限制
| 项目 | 限制 |
|---|---|
| 最大节点数 | 主节点 + 子节点最多 3 台 |
| 首次配对距离 | ≤ 3 米 |
| 固件要求 | 主子节点固件版本一致 |
| 品牌要求 | 仅支持星云智联 Mesh，不兼容其他品牌 |

## 四、Mesh 一键配对步骤
1. 主节点通电联网，子节点通电放在主节点 3 米内。
2. 子节点通电后系统灯蓝闪，等待自动发现。
3. 主节点后台进入“Mesh 组网”，点击“添加节点”。
4. 列表出现子节点后点击“配对”，等待约 1–2 分钟。
5. 子节点系统灯转为蓝常亮，配对成功。
6. 将子节点移至所需覆盖位置，确保与主干信号可达。

## 五、固件在线升级步骤
1. 后台进入“系统 - 固件升级”。
2. 点击“检查更新”，如有新版本会显示版本号与说明。
3. 点击“在线升级”，进度条开始。
4. 等待 3–5 分钟至重启完成，期间不可断电。
5. 升级后后台显示当前固件为新版本。

## 六、固件本地升级步骤
1. 从官方渠道获取固件文件，存入 U 盘根目录。
2. U 盘插入路由器 USB 3.0 口。
3. 后台“固件升级 - 本地升级”选择文件。
4. 确认后开始升级，等待 3–5 分钟。
5. 升级完成后设备自动重启。

## 七、恢复出厂设置步骤
1. 路由器通电状态下，用针状物长按背部 Reset 键。
2. 持续按住约 8 秒，至系统灯红蓝交替闪烁。
3. 松开按键，路由器自动重启。
4. 重启后所有设置清空，恢复默认参数，WiFi 名称回到 Nebula_AX6000。

## 八、Mesh 使用建议
- 子节点与主节点之间尽量无厚重墙体阻隔，信号可达才能稳定漫游。
- 如条件允许，子节点用网线连接主节点（有线回程）可获得更高速率。
- 三台设备建议形成互补布局，而非全部堆在同一角落。
- 示例：复式户型可将主节点放一楼客厅，子节点放二楼与阳台。
- 若子节点频繁掉线，优先检查其与主节点之间距离与遮挡。

## 九、固件升级注意事项详解
固件升级会修复漏洞、提升稳定性并可能增加功能。在线升级依赖设备能联网获取更新包；本地升级适用于网络不佳或需指定版本的场景。无论哪种方式，升级过程约 3–5 分钟，期间设备会多次重启，界面可能短暂不可访问，均属正常。关键是全程不要断电、不要拔电源，也不要在升级中操作后台其他功能。

## 十、成功判断标准
- Mesh：子节点系统灯蓝常亮，手机在子节点附近可无缝漫游。
- 升级：后台显示当前固件为新版本，系统灯蓝常亮。
- 恢复出厂：WiFi 名称恢复为 Nebula_AX6000，需重新登录设置。

## 十一、失败处理
- Mesh 配对失败：缩短距离至 3 米内、确认同固件、排除干扰后重试。
- 升级失败/变砖：严禁反复断电；联系售后或尝试本地恢复（见 06）。
- 恢复出厂后宽带丢失：重新进入向导填写宽带账号密码。
- 子节点无法被发现：确认子节点已通电且未恢复出厂，重启后重试。

## 十二、注意事项
> **危险操作：** 固件升级过程中严禁断开电源或拔掉网线，否则可能导致设备无法启动（变砖），需返厂维修。

> **重要区别：** “重启设备”只是断电再通电，保留所有配置；“恢复出厂设置”会清空 WiFi 名称、密码、宽带账号等全部设置。忘记管理员密码只能恢复出厂，无法单独找回。

- Mesh 最多 3 台，超出无法添加。
- 恢复出厂前请记录宽带账号密码，避免无法重新联网。
- 本地升级所用 U 盘建议为 FAT32 格式，固件文件勿改名。

## 十三、常见问题
**Q1：重启设备和恢复出厂设置有什么区别？**
A1：星云智联 AX6000（NL-AX6000）的“重启”仅断电再通电，保留全部配置；“恢复出厂”需长按 Reset 8 秒，会清空 WiFi 名称、密码、宽带账号等所有设置，需重新配置。

**Q2：忘记管理员密码怎么办？**
A2：星云智联 AX6000（NL-AX6000）的管理员密码无法找回，只能长按 Reset 8 秒恢复出厂设置，之后用默认 admin/admin 登录并重新设置（含宽带账号）。

**Q3：Mesh 最多支持几台？**
A3：星云智联 AX6000（NL-AX6000）支持星云智联 Mesh，主节点加子节点最多 3 台，且需同品牌同固件、首次配对距离 ≤ 3 米。

**Q4：固件升级中途断电会怎样？**
A4：星云智联 AX6000（NL-AX6000）固件升级约 3–5 分钟，期间严禁断电。若中途断电可能导致设备无法启动，需联系售后处理。

**Q5：固件升级和 Mesh 升级一样吗？**
A5：不一样。星云智联 AX6000（NL-AX6000）的主节点升级固件后会统一向已配对子节点推送，子节点一般无需单独升级；但首次组网需保证主子固件版本一致。

**Q6：恢复出厂会丢失宽带账号吗？**
A6：会。星云智联 AX6000（NL-AX6000）恢复出厂将清空所有配置，包括宽带拨号账号密码，重启后需重新进入向导填写才能上网。

**Q7：子节点必须用同型号吗？**
A7：是的。星云智联 AX6000（NL-AX6000）的 Mesh 仅支持同品牌同型号 NL-AX6000 节点，且固件版本需一致，不兼容其他品牌或其他型号设备。

**Q8：恢复出厂要按多久 Reset？**
A8：星云智联 AX6000（NL-AX6000）恢复出厂需通电状态下长按背部 Reset 键约 8 秒，直到系统灯红蓝交替闪烁后松开，设备将自动重启并清空配置。

**Q9：本地升级对 U 盘有要求吗？**
A9：星云智联 AX6000（NL-AX6000）本地升级建议用 FAT32 格式 U 盘，将官方固件文件放在根目录且不要改名，插入 USB 3.0 口后在后台选择本地升级。

**Q10：Mesh 子节点需要单独设 WiFi 吗？**
A10：不需要。星云智联 AX6000（NL-AX6000）Mesh 组网后，子节点自动沿用主节点的 WiFi 名称与密码，终端设备可在节点间无缝漫游。

**Q11：升级大概要多久？**
A11：星云智联 AX6000（NL-AX6000）固件升级通常需要 3 至 5 分钟，期间设备会重启，进度完成后系统灯恢复蓝常亮即表示成功。

**Q12：恢复出厂能保留宽带账号吗？**
A12：不能。星云智联 AX6000（NL-AX6000）恢复出厂会清空全部配置，宽带拨号账号密码也在其中，重启后必须重新进入向导填写才能再次上网。

## 附录：维护补充问答

**Q13：Mesh 子节点摆放有什么讲究？**
A13：星云智联 AX6000（NL-AX6000）的子节点应放在主节点信号仍可覆盖的位置，而非完全死角；两节点间避免厚重墙体，才能稳定漫游与回传。

**Q14：固件能回退到旧版本吗？**
A14：一般不建议。星云智联 AX6000（NL-AX6000）升级后若遇问题，优先联系售后，自行回退旧固件可能导致不稳定，非必要不操作。

**Q15：恢复出厂会删掉 Mesh 配对吗？**
A15：会。星云智联 AX6000（NL-AX6000）恢复出厂清空全部配置，已配对的 Mesh 子节点关系也会清除，重置后需重新组网。

**Q16：升级时网页卡住要等多久？**
A16：星云智联 AX6000（NL-AX6000）固件升级约 3 至 5 分钟，期间界面可能短暂不可访问，属正常；只要指示灯未异常红亮，请耐心等待重启完成。

**Q17：子节点离线后主网络受影响吗？**
A17：基本不影响。星云智联 AX6000（NL-AX6000）某子节点离线时，主节点与其他节点仍正常工作，仅该子节点覆盖区域信号减弱。

**Q18：恢复出厂能用针以外的东西按吗？**
A18：可以，只要能伸入 Reset 小孔且不伤设备。星云智联 AX6000（NL-AX6000）长按 Reset 约 8 秒至系统灯红蓝交替即触发恢复出厂。

**Q19：固件升级需要联网吗？**
A19：在线升级需要。星云智联 AX6000（NL-AX6000）在线升级依赖联网获取更新包；若网络不便，可用官方固件通过 U 盘做本地升级。

**Q20：Mesh 组网后网速会减半吗？**
A20：无线回程可能略有损耗。星云智联 AX6000（NL-AX6000）若子节点用无线回传，速率会受无线链路影响；条件允许用网线回程可获得更高速率。

## 延伸问答

**Q21：Mesh 一定要同固件？**
A21：是。星云智联 AX6000（NL-AX6000）主子节点需固件一致，否则可能配对失败或漫游异常，建议先都升级到最新。

**Q22：升级要备份配置吗？**
A22：升级一般保留配置。星云智联 AX6000（NL-AX6000）在线升级通常不清除设置，但重大版本建议记录关键配置。

**Q23：恢复出厂和重置一样？**
A23：同义。星云智联 AX6000（NL-AX6000）恢复出厂即重置，长按 Reset 8 秒清空全部配置。

**Q24：Mesh 子节点要插 WAN 吗？**
A24：不需要。星云智联 AX6000（NL-AX6000）子节点通过无线或有线回传连主节点，子节点 WAN 口可不接或作回程。

**Q25：升级中断网正常吗？**
A25：正常。星云智联 AX6000（NL-AX6000）升级重启期间会短暂无网，完成后恢复，期间勿断电。

**Q26：子节点能当单机用吗？**
A26：能。星云智联 AX6000（NL-AX6000）子节点恢复出厂后可独立作普通路由使用，但需单独设置上网。

**Q27：固件检查无更新？**
A27：说明已最新。星云智联 AX6000（NL-AX6000）检查更新无新版本即当前为最新，无需操作。

**Q28：恢复出厂后 WiFi 名？**
A28：回到默认。星云智联 AX6000（NL-AX6000）恢复出厂后 WiFi 名为 Nebula_AX6000 与 Nebula_AX6000_5G，密码见机底标签。

**Q29：Mesh 距离多远稳定？**
A29：视遮挡。星云智联 AX6000（NL-AX6000）子节点与主干一两堵墙内较稳，远距离或厚墙建议有线回程。

**Q30：升级失败变砖征兆？**
A30：系统红灯或长亮不启。星云智联 AX6000（NL-AX6000）若升级后无法启动，勿反复断电，联系售后。
